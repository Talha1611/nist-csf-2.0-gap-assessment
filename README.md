# NIST Cybersecurity Framework (CSF) 2.0 Gap Assessment

## Project Overview

This self-directed project demonstrates the application of the NIST Cybersecurity Framework (CSF) 2.0 to a simulated financial services organization, **NorthStar Financial Services**.

The objective was to assess the organization's current cybersecurity practices against selected NIST CSF 2.0 outcomes, identify gaps and associated risks, define target states, and develop risk-based remediation recommendations.

> **Disclaimer:** NorthStar Financial Services is a fictional organization created solely for this portfolio project. The evidence, findings, and recommendations presented in this repository are simulated for educational purposes.

## Organization Scenario

NorthStar Financial Services is a simulated Canadian financial services organization with approximately 180 employees. Its environment includes:

- Microsoft 365
- Active Directory
- Cloud-based applications
- Remote employees
- Customer financial information
- A six-person IT team

Management has implemented several cybersecurity practices but has not previously performed a formal assessment against NIST CSF 2.0.

## Assessment Methodology

The assessment followed the following approach:

**Evidence → Current State → Gap → Risk → Target State → Recommended Action → Priority**

For each selected CSF outcome:

1. Available evidence was reviewed.
2. The current cybersecurity state was documented.
3. Gaps between the current and desired state were identified.
4. Risk scenarios associated with identified gaps were considered.
5. Likelihood and impact were used to support risk prioritization.
6. Target states were defined.
7. Risk-based remediation actions were recommended.

## Assessment Scope

The project evaluated selected outcomes across multiple NIST CSF 2.0 Functions.

| CSF Outcome | Assessment Area |
|---|---|
| ID.AM-01 | Hardware Asset Management |
| ID.RA-01 | Vulnerability Management |
| ID.IM-04 | Incident Response Planning |
| PR.AA-03 | Authentication |
| PR.AA-05 | Access Authorization and Privileged Access |
| PR.DS-11 | Backup Management and Restoration Testing |
| DE.CM-01 | Network Monitoring |
| GV.PO-02 | Cybersecurity Policy Maintenance |

## Key Findings

The assessment identified opportunities to improve:

- Hardware inventory completeness and reconciliation
- Authentication for legacy applications
- Periodic privileged-access reviews
- Backup restoration testing
- Vulnerability tracking and remediation follow-up
- Proactive network monitoring
- Cybersecurity policy maintenance
- Incident response plan testing and maintenance

## CSF Tier Assessment

Based on the simulated evidence, NorthStar was assessed as:

**Current Tier: Tier 2 – Risk Informed**

Cybersecurity practices exist and cybersecurity risk is recognized, but practices are not consistently formalized, reviewed, or implemented across the organization.

**Target Tier: Tier 3 – Repeatable**

The target is to establish more formal, consistently implemented, reviewed, and maintained cybersecurity risk management practices across the organization.
